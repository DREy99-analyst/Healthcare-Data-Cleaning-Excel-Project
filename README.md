# Healthcare-Data-Cleaning-Excel-Project
Project Overview

A healthcare data cleaning project using Microsoft Excel, demonstrating data inspection, duplicate removal, data validation, data standardization, and INDEX-MATCH lookup techniques.

The project focuses on improving the quality, consistency, and organization of a healthcare dataset to make patient records easier to retrieve and work with.

Project Objectives

Inspect the raw healthcare dataset and identify data quality issues.

Identify and remove duplicate records.

Standardize inconsistent text entries.

Review and format date columns.

Apply Excel Data Validation.

Use INDEX-MATCH to retrieve patient information.

Organize the cleaned dataset for easier access.

Dataset Information

Dataset Name: Healthcare Dataset

Source: Kaggle

Original Records: 55,500

Cleaned Records: 54,966

Total Columns: 15

The dataset contains patient information such as age, gender, blood type, medical condition, admission date, discharge date, hospital, insurance provider, medication, billing amount, and test results.

Data Cleaning Process

Data Inspection: Reviewed the raw dataset and examined its structure.

Duplicate Removal: Removed 534 duplicate records.

Data Standardization: Corrected inconsistent text formatting.

Date Formatting: Reviewed and formatted the admission and discharge date columns.

Data Validation: Applied Excel Data Validation to support consistent selections and record retrieval.

INDEX-MATCH: Created a lookup section to retrieve patient information based on selected names and fields.

Project Results

Reduced the dataset from 55,500 to 54,966 records.

Improved consistency in text formatting.

Reviewed and standardized date entries.

Created an Excel lookup section for retrieving patient records.

Organized the cleaned data into a more usable structure.
